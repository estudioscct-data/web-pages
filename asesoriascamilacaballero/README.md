# 💄 Camila Caballero – Asesoría de Imagen & Fashion Stylist

[![Website](https://img.shields.io/badge/website-live-green)](https://estudioscct-data.github.io/web-pages/asesoriascamilacaballero/)

Sitio web profesional para una asesora de imagen y fashion stylist. Muestra sus servicios, permite reservar citas y gestiona pagos para clientes en Bolivia y el extranjero.

## 🌐 Sitio en producción

El sitio **no está alojado en GitHub Pages**. Se encuentra activo y funcionando en su dominio oficial para clientes reales. Este repositorio es únicamente para fines de portafolio y control de versiones.

## 🎯 Propósito

El sitio fue diseñado para:

- Presentar los servicios de asesoría de imagen (colorimetría, styling pro, armario inteligente, personal shopper, etc.).
- Permitir a las clientas reservar citas y realizar pagos integrados (Bolivia e internacional).
- Reflejar la identidad de la marca: **elegancia, confianza y estrategia de imagen personal**.

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|------------|------|
| HTML5, CSS3 | Estructura y estilos personalizados |
| JavaScript (Vanilla) | Interactividad (modales, redirecciones, lógica de pagos) |
| Google Fonts (Poppins) | Tipografía profesional |
| Formularios de Google | Captación de clientas (lista de espera) |
| Google Calendar | Integración de horarios disponibles |

## ✨ Características destacadas

- **Diseño responsivo** – Adaptado a móviles, tablets y escritorio.
- **Sistema de reservas** – Integración con Google Calendar y WhatsApp.
- **Múltiples métodos de pago** – Transferencias bancarias (Bolivia) y pagos internacionales.
- **Modales informativos** – Políticas de cancelación antes de redirigir al pago.
- **Estilo visual coherente** – Paleta de colores (burdeos, arena, marrón) alineada con la identidad de la marca.
